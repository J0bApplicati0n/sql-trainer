# SQL Fraud Trainer v0.1

Мобильный SQL-тренажёр на учебной базе `clients / transactions`.

## Что уже есть
- случайные задания;
- фильтр по максимальному уровню;
- включение/выключение тем;
- будущие темы `window` и `LAG/LEAD` уже заложены, но по умолчанию отключены;
- проверка ответа по **результату выполнения**, а не по тексту SQL;
- подсказка;
- эталонный запрос после ошибки;
- локальная статистика верных/неверных ответов;
- PWA-интерфейс под Android;
- после первого успешного запуска может работать офлайн.

Текущий уровень по умолчанию: **7** — до CTE и подзапросов включительно.
Оконные функции находятся на Level 8, `LAG/LEAD` — Level 9.

## Важный момент про Android / PWA
Service Worker требует HTTPS или `localhost`.

### Самый удобный вариант
1. Разместить содержимое папки на любом статическом HTTPS-хостинге (например GitHub Pages).
2. Открыть ссылку в Chrome на Android.
3. Один раз запустить приложение при наличии интернета — загрузится SQL.js.
4. В меню Chrome выбрать **"Добавить на главный экран" / "Установить приложение"**.
5. После кэширования приложение работает офлайн.

### Строго локально на телефоне
Можно запускать папку через локальный HTTP-сервер в Termux и открывать:
`http://127.0.0.1:8080`
Это считается secure-context исключением для `localhost`, поэтому PWA/Service Worker работают.
Для такого режима на телефоне нужен Python/Termux.

## Проверка
В v0.1 разрешены только `SELECT` и `WITH`.
Это сделано специально, чтобы пользовательский запрос не мог случайно изменить/сломать тренировочную БД.
Каждая проверка выполняется на свежей копии базы.

## Как добавлять задания
Редактируй `tasks.json`.
У задания есть:
- `level` — порог уровня;
- `difficulty` — сложность 1–5;
- `topics` — необходимые темы;
- `prompt`, `hint`, `solution`;
- `orderMatters` — важен ли порядок строк.

Если задача помечена `["window"]`, она не попадёт в пул, пока тема Window Functions не включена и максимальный уровень не поднят до 8.

## База
Исходная база лежит в `db.sql`.
